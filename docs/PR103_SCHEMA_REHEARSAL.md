## Rollback-only local rehearsal helper

`scripts/build-pr103-rehearsal.mjs` generates an ordered **rollback-only** SQL script for an isolated disposable database that has the installed site guard and weekly base. It checks both function bodies and selected privileges, the enabled trigger and selected INSERT ACLs; excludes the already-installed guard, weekly base and paid-review RPC; runs the remaining five migrations with the time-detail sequence safeguard in the same transaction; checks selected RLS/grants; and ends in `ROLLBACK`. Inputs carry SHA-256 comments and a conservative transaction-control tripwire. `tests/pr102-migration-sequence.test.ts` exercises this exact generated SQL in PGlite, including a missing/disabled guard, a late function-name collision and rollback, preserved fixture records and a successful rollback. This helper is **not** a deployment script, a comprehensive ACL/catalog check, or a substitute for an isolated hosted-equivalent PostgreSQL rehearsal. Even rolled-back DDL can lock tables: **never run it against a shared database**. A fresh generated script needs manual review, including transaction boundaries, before use.
