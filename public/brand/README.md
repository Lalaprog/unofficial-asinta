# Asinta Corp. Brand SVG Assets

Upload your official SVG files into this folder (`public/brand/`) using these exact filenames:

1. **`asinta-emblem.svg`** — The Concrete Hollow Block (CHB) mark / icon.
2. **`asinta-wordmark.svg`** — The `asinta corp.` text wordmark.

> **Note:** Keep this `README.md` file in the folder so GitHub does not delete the `public/brand/` directory when you delete or replace SVG files. Any SVG canvas size (`viewBox` / `width` / `height`) will automatically scale to fit the Login page and Footer.
