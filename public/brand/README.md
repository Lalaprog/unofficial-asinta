# Asinta Corp. & BALE Brand SVG Assets

Upload your official SVG files into this folder (`public/brand/`) using these exact filenames (lowercase):

1. **`asinta-emblem.svg`** — The Concrete Hollow Block (CHB) mark / icon.
2. **`asinta-wordmark.svg`** — The `asinta corp.` text wordmark.
3. **`bale-logo.svg`** — The `BALE` system name / wordmark SVG.

> **Note:** Keep this `README.md` file in the folder so GitHub never deletes the `public/brand/` directory when you replace SVG files. Even if your SVG converter (such as VTracer) omits the `viewBox` attribute or uses large dimensions, `AsintaLogo.tsx` automatically injects the `viewBox` from the SVG's `width`/`height` and scales it cleanly.
